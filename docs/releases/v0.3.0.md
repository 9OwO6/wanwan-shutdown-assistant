## 晚晚 v0.3.0 — 更小、更懂周末、可以选睡眠

**下载变小 4 倍：103 MB → 约 25 MB。** 解压后双击 `启动晚晚.vbs`（或 `启动晚晚.cmd`），先点「体验睡前倒计时」试试——35 秒演示，绝不关机。

### 新功能
- **到点后可以选「睡眠」**：窗口和文件都保留，醒来接着用；唤醒后会重新给两分钟收尾，不会一醒来又睡过去。
- **周末作息**：周五、周六晚上可以单独设一个更晚的睡觉时间（例如 01:00）。
- **桌面快捷方式**：右键托盘 →「在桌面创建晚晚快捷方式」。

### 改进
- 语音改为 MP3、角色图片无损观感压缩，下载包从 103 MB 降到约 25 MB。
- 开机自启不再依赖正在被 Windows 淘汰的 VBScript；旧版自启快捷方式会自动迁移。另附 `启动晚晚.cmd` 备用启动方式。
- 夜晚区间结束后自动收起遗留的倒计时窗口。
- 音色选择改为可读名称，并说明 N1 是唯一的完整台词包。
- README 改为中文优先，增加 SmartScreen、安全性、卸载等常见问题。
- 新增 GitHub Actions：打 tag 自动构建、审计并发布精简包。

### English
Slimmer portable package (103 MB → ~25 MB, MP3 voice + palette-quantized art), **sleep** as an alternative to shutdown with a fresh save window after resume, **Friday/Saturday weekend bedtimes**, VBScript-free autostart (old shortcuts migrate automatically), a desktop-shortcut tray command, and tag-triggered release builds. 21 schedule boundary tests; WPF test modes cover the sleep path with simulated requests only.

The UI and voice are Simplified Chinese. No model, GPU or SDK is needed at runtime. This is a source-based portable preview, not a signed installer; see LICENSE and NOTICE.md.
