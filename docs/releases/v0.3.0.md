## 晚晚 v0.3.0 — 起夜监督、早睡打卡、一键更新，下载包小了 4 倍

**下载 → 解压 → 双击 `启动晚晚.vbs`（或 `启动晚晚.cmd`）。** 先点「体验睡前倒计时」：35 秒演示，绝不关机。

### 新功能
- **起夜监督**：关机/睡眠后的几个小时里（默认 6 小时）偷偷开机，晚晚会出来说“怎么又偷偷起来呀”，给你几分钟（默认 5 分钟）处理急事，然后再帮你关机或睡眠。真有急事可以「今晚真的有急事」取消当晚监督，第二天照常。
- **早睡打卡**：自动记录每晚有没有按时睡，主界面显示连续早睡天数和最近 7 晚；早上见面时晚晚会告诉你昨晚的结果。
- **一键更新**：「检查更新」从 GitHub 下载新版、校验 SHA-256 后自动重启安装，设置和打卡记录都保留；每天最多自动检查一次。
- **到点后可以选「睡眠」**：窗口和文件都保留；醒来会重新给你收尾时间。
- **周末作息**：周五、周六晚上可以单独设一个更晚的睡觉时间。
- **桌面快捷方式**：右键托盘 →「在桌面创建晚晚快捷方式」。

### 改进
- 下载包从 103 MB 降到约 25 MB（MP3 语音 + 观感无损压缩的角色图）。
- 角色动画改用 40 张逐帧检查过的独立透明帧，去掉了相邻袖子串入的问题。
- 开机自启不再依赖正在被 Windows 淘汰的 VBScript，旧快捷方式自动迁移。
- README 中文优先，增加 SmartScreen、安全性、联网、卸载等常见问题。
- 打 tag 自动构建、审计并发布精简包。

> 起夜监督需要勾选「开机陪伴」，晚晚才能在开机后出现。从 v0.2.x 升级需要手动下载这一版；之后的版本都可以在晚晚里一键更新。

### English
Sleep watch (a “caught you” countdown when the computer is turned back on during the sleep window, with a configurable grace period and a one-night emergency cancel), bedtime streaks with a morning greeting, one-click updates from GitHub releases with SHA-256 verification, sleep as an alternative to shutdown, Friday/Saturday bedtimes, a 4× smaller package (~25 MB) and reviewed character frames. The UI and voice are Simplified Chinese; no model, GPU or SDK is needed at runtime.
