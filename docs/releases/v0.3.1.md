## 晚晚 v0.3.1：设置单独成页，声音只留晚晚

**已经装了 v0.3.0：** 在晚晚里点「检查更新」就能一键升级，设置和打卡记录都会保留。
**第一次用：** 下载、解压，双击 `启动晚晚.vbs`（或 `启动晚晚.cmd`）。

### 改进
- **新的「⚙ 设置」窗口**。所有约定都集中在一处：睡觉时间、周五六晚、收尾时间、关机或睡眠、到点守护、起夜监督、声音和称呼、桌面陪伴、减少动态、开机陪伴、自动检查更新。
- **主窗口更清爽**，只留下今晚的状态、早睡打卡和几个快捷操作：听提醒、体验倒计时、互动小剧场。新增「开启到点守护 / 暂停守护」一键开关。
- **声音只保留晚晚（N1）**。删掉了有杂音的 A/B/C/D 试验音色和「音色试听」窗口。
  - 选过旧音色的设置会自动换成晚晚的声音。
  - 设置里还可以改用 Windows 系统朗读。
  - 没有录音的文字会自动用系统朗读。
- 更新后会自动清理旧版本留下的音色文件。
- 以后的更新会使用新版本自带的安装程序。

### English
A dedicated settings window holds every option; the main window keeps tonight's status, the streak, quick actions and a one-click guard on/off switch. The noisy prototype voices A/B/C/D and the audition window were removed. N1 is the only bundled voice, with Windows speech as an option and as the fallback. Older settings migrate automatically, and leftover files from earlier versions are removed after updating.
